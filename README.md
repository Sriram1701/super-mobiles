# Super Mobiles - Sales & Service, Cuddalore Old Town

Official website for **Super Mobiles**, a premier phone repair and accessories center in Cuddalore Old Town run by Bharath.

## ✨ Features
- **Mobile First Design**: Fully responsive, touch-optimized UI with modern glassmorphism and fluid typography.
- **App-Style Sticky Bottom Bar**: Quick actions for Direct Call, WhatsApp inquiry, Repair booking, and Google Maps location.
- **Express Repair Services**: Display & glass replacement, battery swap, motherboard IC fixes, and software recovery.
- **Direct WhatsApp Booking**: Seamless modal form to send pre-filled booking details directly to WhatsApp.
- **Built-in Node.js Server**: Lightweight zero-dependency static file server (`server.js`).

## 🚀 Running Locally
```bash
node server.js
```
Open [http://localhost:8080](http://localhost:8080) in your browser.
